# Python - Manipulação de Strings e Cálculos Avançados

## 📋 Sobre o Projeto
Coleção de programas Python que demonstram habilidades em manipulação de texto, algoritmos de verificação e cálculos complexos, representando um avanço significativo na jornada de programação.

## 🚀 Tecnologias Utilizadas
- **Python 3**
- **Manipulação de Strings**
- **Algoritmos de Verificação**
- **Cálculos Matemáticos Complexos**
- **Funções e Modularização**

## 📁 Programas Desenvolvidos

### 1. Calculadora de Gorjeta
- **Arquivo:** `1_calculadora_gorjeta.py`
- **Descrição:** Calcula gorjetas baseadas em porcentagens customizáveis sobre o valor da conta
- **Habilidades:** Cálculos percentuais, formatação monetária, experiência do usuário

### 2. Verificador de Palíndromo
- **Arquivo:** `2_verificador_palindromo.py`
- **Descrição:** Identifica se uma palavra ou frase é um palíndromo (lê-se igual de trás para frente)
- **Habilidades:** Manipulação de strings, slicing, lógica algorítmica, tratamento de case e espaços

### 3. Calculadora de Desconto Versão 2
- **Arquivo:** `3_calculadora_desconto_v2.py`
- **Descrição:** Versão aprimorada com múltiplos descontos, cálculos progressivos e relatório detalhado
- **Habilidades:** Cálculos encadeados, formatação de saída, melhoria iterativa de código

### 4. Idade em Dias
- **Arquivo:** `4_idade_em_dias.py`
- **Descrição:** Converte anos de vida em dias totais, considerando anos bissextos
- **Habilidades:** Cálculos temporais complexos, consideração de variáveis calendário, precisão matemática
